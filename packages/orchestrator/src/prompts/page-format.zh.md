> 本资产是页面的**硬性格式契约**。
> 与文风纪律（`humanizer.*.md`，反 AI 腔）和读者优先纪律
>（`reader-first.*.md`，教会读者）正交：这里只规定「格式必须成立」，
> 不规定「怎么写得好读」。

## YAML frontmatter

- 页面的 `--- ... ---` frontmatter 由 `write_page` 工具按 `slug` / `title` 参数**自动注入**，
  你**不得手写** frontmatter（写了会被工具覆盖，且容易与 wiki.json 不一致）。
- 输出正文以第一个 `#` 一级标题开始。

## 标题层级

- 全文**只有一个**一级标题（`#`），与页面标题一致；不得重复 H1、不得跳级
  （如 `##` 之后直接 `####`）。
- 二级标题（`##`）按页面诊断出的主题块划分，每个二级标题下必须有**实质散文**，
  不能是标题列表。
- 源码导航节的标题固定：形态 A（概览）用 `## 🧭 源码导航 (Codebase Map)`；
  形态 B/C/D（局部模块）用 `## 🔗 关联模块与上下游`。不要自创标题。

## Mermaid 图表

- **必须**使用 Mermaid（\`\`\`mermaid）绘制架构图或模块依赖图。
- Mermaid flowchart 节点标签必须使用 quoted label：`A["节点文本"]`。凡标签包含括号、HTML 换行（如 `<br/>`）、竖线、花括号、路径、符号或中英文混排时，禁止裸写 `A[节点文本]`，必须写成 `A["节点文本"]`。
- Mermaid 图表输出前必须自检语法，尤其避免 `A[O(n) 说明]` 这类未加引号标签；正确写法是 `A["O(n) 说明"]`。
- **反注水**：只有本页真正涉及模块拓扑关系时才画图。页面不涉及拓扑关系时，
  Mermaid 图数的正确答案是 **0**（`minimal` 档位的全景导览是唯一强制作图例外）；
  **不得为凑图表而加图**。

## 溯源格式（`Sources:`）

这是系统最核心的交互功能，**绝不允许遗漏**：

- 当你结束一个子章节，或者对某个架构设计、核心类、业务逻辑进行了详细的文字论述后，
  **必须在段落末尾添加该结论来源的具体文件路径溯源**。
- 格式（严格遵守）：空一行后，使用 `Sources: [文件名](文件路径#L起始行-L结束行)`。
  如果没有行号，只保留文件路径。支持多个溯源，用逗号分隔。

正确示例：

> Midscene.js 的核心层提供了 AI 推理与任务调度能力。Agent 封装了用户意图，协调 AI 与设备操作...
>
> Sources: [agent.ts](packages/core/src/agent/agent.ts#L1-L50), [package.json](packages/core/package.json)

## 代码块

- 代码片段**只允许**来自关联文件（照抄或节选），不得凭空编写「示例代码」。
- **反注水**：关联文件里没有可写代码（纯配置 / 纯类型声明 / 纯 Markdown）时，
  代码块数的正确答案是 **0**——强行加代码块等于编造源码，是失败而不是达标。
- 不得为凑字数而堆术语表；术语表只有在术语确实密集且需要统一解释时才写。

## 交付前自检清单

输出 `write_page` 之前逐条确认（对齐 lecture-to-notes 的交付检查清单，
语境从「课堂笔记」改为「代码 wiki」）：

1. 每个二级标题下有**实质散文**，不是标题列表或纯图表堆砌。
2. 每个关键论断后都有 `Sources:` 行，指向真实存在的文件（路径 / 行号不凭空编写）。
3. 全部 Mermaid 节点标签加了引号。
4. 引用的文件路径**真实存在**（用 `read` / `find` 确认过，不是猜的）。
5. 代码片段来自关联文件（照抄或节选），不是凭空编写的「示例代码」。
6. 没有凭空发明的接口、函数签名、参数、返回值或版本号。
7. 没有聊天机器人残留（「让我们一起来看看」「值得注意的是」）、营销长句、
   或装饰性加粗（加粗只用于首次引入的核心概念）。
8. 章节以**具体事实**收尾，不以「未来可期」「值得期待」这类空话收尾。
9. 没有同义改写注水（同一论断换词重复、同一段意思拆成两段讲）。
10. 没有把 README / AGENTS.md / CHANGELOG 整段复制当散文——项目说明已通过
    `<project_context>` 自动注入，页面只需讲解代码本身，不需要复述文档。
11. Mermaid 与代码块数量符合「源没有就应该是 0」的口径（本页不涉及拓扑时图为 0；
    关联文件没有可写代码时代码块为 0）。
